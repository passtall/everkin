# Biome backgrounds

Generated by `tools/backgrounds/gen_backgrounds.py` (first pass, 2026-10-08). One card background (1024 × 1536, faceted like the creature art) and one battle background (1920 × 1080, smooth and glowing) per biome in game_system.md §14.5.

Regenerate: `python3 tools/backgrounds/gen_backgrounds.py OUT_DIR [biome_id ...]` writes SVGs to `OUT_DIR/card` and `OUT_DIR/battle`; render them to PNG in a browser (Chromium) and convert to WebP.
