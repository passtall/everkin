# Biome backgrounds

Generated by `tools/backgrounds/gen_backgrounds.py` (first pass, 2026-10-08). One card background per biome in game_system.md §14.5 (1024 × 1536, faceted like the creature art).

Regenerate: `python3 tools/backgrounds/gen_backgrounds.py OUT_DIR [biome_id ...]` writes SVGs to `OUT_DIR/card` (its battle mode is no longer used); render them to PNG in a browser (Chromium) and convert to WebP.

## Battle backgrounds

`battle/<biome_id>.png`: photo-real night scenes, one per biome (2026-10-08). Source size 1672 × 941; crop to 16:9 and scale to 1920 × 1080 at build time.
