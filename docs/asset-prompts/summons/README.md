# Everkin — summon and construct artwork

14 individual PNG assets, generated using the built-in image generation tool.
Final prompts are recorded in prompts.md. Creature style-reference images were not available, so the supplied written style specification was used.

All 14 exported assets passed validation: 1024 × 1536 RGBA PNG, real transparent background, minimum 48 px safe margins, and lowest visible pixel at y = 1456. Faint alpha residue was cleaned during export; subjects were fitted proportionally and aligned without altering their designs.

The overview image uses a dark plum backdrop for preview only. Individual assets have no backdrop, card frame, lettering or summon marker, as requested by the art briefs. No undead art was generated.

The extra clay-golem cleanup variation was inspected and discarded; the original generated golem was used for the final export.
