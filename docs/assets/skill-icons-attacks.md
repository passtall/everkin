# Unique attack icons (319)

One action bar icon per creature's unique attack. **Complete (2026-11-14): 319/319 generated and visually reviewed at 64 × 64 px.**

Final reference PNGs are saved in `docs/assets/skill-icons-attacks/<file>` (repository root); runtime skill IDs remain unchanged. Use `assets/icons/skills/<file>` for runtime copies (the file name is the skill ID: the name in snake case, apostrophes and punctuation dropped). The game draws the slot frame, name, key number and gems; the icon is only the picture inside. Overview and status of all icons: [skill-icons.md](skill-icons.md).

## How to run

1. Attach the creature's card art from the Reference art column (`assets/creatures/<art file>`).
2. Paste: "Use the attached creature only as a reference for the weapon, prop or body part and its colors. Do not draw the whole creature.", then the row's subject, then the style block below. One image per request.
3. Check it at 64 × 64 px: the motion and the accent must both read.

When an attack changes in [creature-classes.md](../creature-classes.md), change its row here: the file name follows the attack name, the motion follows the style column, the accent follows the effect. Accent colors match the status icons in [ui-icons.md](ui-icons.md).

## Style block (paste after the subject)

```
Make ONE separate square game icon for the subject described above, for the action bar of the Everkin card game (a night fairytale creature card battler).

FORMAT
- PNG, 512 × 512 px, square, full bleed (no transparent border, no rounded corners, no frame: the game draws its own bronze slot frame).
- No text, letters, numbers or logos.

STYLE
- One bold central symbol that reads clearly at 64 × 64 px. Simple silhouette first, detail second.
- Chunky low-poly faceted style matching the game's creature art: broad flat facets, matte colors, soft light from the upper left.
- Background: a dark plum-to-midnight-blue gradient with a faint vignette, the same on every icon so the set reads as one.
- The symbol uses the colors of the reference plus one brighter accent glow. High contrast against the dark background.
- Storybook tone for ages 7 and up: no blood, gore or skulls dripping anything.
```
